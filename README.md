# InfraSec Lab
> Segmentação, Monitoramento e Resposta a Incidentes em Ambiente de Rede Simulado

![status](https://img.shields.io/badge/status-em%20desenvolvimento-blue)

## Objetivo
Laboratório prático que simula a implantação, proteção, gestão de identidade, monitoramento e resposta a incidentes em uma rede corporativa segmentada.
